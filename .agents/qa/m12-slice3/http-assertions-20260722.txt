## Verdict
PASS — real admin login works end-to-end (12.3): correct creds authenticate, wrong creds are
rejected 401, the session is an httpOnly HMAC cookie (NOT `ADMIN_TOKEN`), the admin token never
appears in served HTML (the load-bearing 12.3 security assertion), the session resolves server-side
to the admin email, and protected routes fail closed to `/login` when logged out.
